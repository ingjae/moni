# Moni v0.0.9

- Settings → Updates → **Check now** asks GitHub right away instead of waiting for the daily check. When a release is waiting the button turns into **Update**, which installs it with the same SHA-256 verification the Shell uses.

From v0.0.7 this release arrives through the in-app update notification. Upgrading from v0.0.6 or older: install it once by hand (zip below or `make install`).

Validated in an isolated headless GNOME 46 shell by clicking the button: as 0.0.7 it found v0.0.8 and installed the real zip; as 0.0.8 it reported up to date.
