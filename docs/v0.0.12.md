# Moni v0.0.12

- **Settings, reorganized:** the window opens on an overview: a search field, Updates (version, *Check now*, daily check, auto install) and one row per settings page — Top bar, Robotics, Orca sessions, Screenshot & recording, Clipboard history, Quick copy, Appearance, Backup, About. Each row says what is inside and opens its page.
- **Search** finds any setting across every page; a result opens the page it is on.
- **Orca session dots** are brighter and more saturated with a soft glow; the working pulse no longer dims the green as much.

Validated in an isolated headless GNOME 46 shell: overview, a settings page, search and opening a result, in light and dark.
