# Moni v0.0.4

Clipboard history and settings backup.

- **Clipboard history** (`Super+Shift+V` or the 📋 panel icon): type to search, Enter or click pastes straight into the window you came from (`Ctrl+Shift+V` in terminals). ★ favorites stay on top and are saved; recent items live in memory until logout. Copies flagged by password managers (`x-kde-passwordManagerHint`) are skipped. Text only.
- **Settings → Backup**: export every setting, shortcut and ★ favorite to `moni-settings.json`, import it on another machine. Values are type-checked; unknown or mistyped keys are skipped, not coerced.
- New keys: `show-clipboard`, `clipboard-shortcut`, `clipboard-paste`, `clipboard-size`, `clipboard-favorites`.
- `make test` now also syntax-checks the ES-module sources and runs a settings export → import round trip.

Validated on GNOME 46 in an isolated nested Wayland shell: search-and-Enter and click paste into GNOME Text Editor, `Ctrl+Shift+V` paste into GNOME Terminal (pasted, not executed), favorites persisting across a shell restart, disable/enable ×3, and Export/Import through the real file dialogs.

Both GNOME 42–44 and 45–48 archives are included. The GNOME 42–44 runtime, clipboard images, and paste into apps with non-standard paste shortcuts were not tested.
