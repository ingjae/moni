# Moni v0.0.10

- **Fix:** Settings → Updates → *Check now* failed with `this.metadata['shell-version'] is undefined`. The settings window receives metadata over D-Bus, which drops arrays; the Shell version is now read from the installed `metadata.json`.
- **Panel numbers (#3):** when a value changes, the whole chip is repainted instead of only the new glyphs. This targets reports of the CPU % showing leftover digits (e.g. `90` for 9 %) while screen recordings look correct. It could not be reproduced here, so #3 stays open until confirmed.

Validated in an isolated headless GNOME 46 shell: with metadata shaped like the real D-Bus copy (no arrays) the old code reproduced the error and the fixed code found and installed a release; `make test` passes. The X11 *Restart now* path was confirmed on a real session while updating to v0.0.9.
