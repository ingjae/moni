# Moni v0.0.7

Moni now updates itself from GitHub Releases.

**Updates**
- Once a day Moni checks the latest release. A notification offers **Update** and **Release notes**; the dropdown shows *Update to Moni x.y.z* until it is applied.
- **Update** downloads the zip for your GNOME version (42–44 or 45–48), verifies it against the SHA-256 digest GitHub publishes, and installs it with `gnome-extensions install --force`. Only assets from `github.com/ingjae/moni` with a digest are accepted.
- **X11:** *Restart now* reloads GNOME Shell with your windows still open. **Wayland:** log out and back in.
- Settings → **Updates**: *Check for updates* (on by default) and *Install automatically* (off by default). New keys: `update-check`, `update-auto`.
- The download and install run in the helper process, so the shell never blocks.

**Upgrading from v0.0.6 or older:** install this release once by hand (zip below or `make install`). From v0.0.7 on, updates arrive by notification.

Validated on GNOME 46 in an isolated headless shell: a fake 0.0.5 install found v0.0.6 on its own, showed the notification and menu item, and **Update** installed the real v0.0.6 zip after the SHA-256 check; a tampered digest and a foreign URL were refused (`make test` covers the asset rules). The X11 restart path and the GNOME 42 (libsoup 2.4) download path were not run.
