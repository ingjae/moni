# Moni v0.0.2

Scope: complete the six findings from the design and behavior review.

- [x] Keep recording status visible until StopScreencast confirms success; show stopping state, prevent duplicate stops, and report refusal/timeouts without a false saved notification.
- [x] Select the shortest known rosbag disk ETA for the panel and list all recordings in the dashboard.
- [x] Prioritize active recording, CAN and ROS domain alerts when fitting panel chips; allow smaller chips to use remaining room.
- [x] Increase dashboard detail size and opacity, wrap long details, add graph time ranges and network/disk legends, and keep the dashboard inside a bounded scroll area.
- [x] Separate editor tools and colors, allow tool scrolling, and shorten/wrap the status line for smaller windows.
- [x] Describe TCP probe failure as probe-host unreachability rather than global internet loss.

Additional correction: refresh the default-route star when the route changes without an address change.

Validation: collector tests, legacy build/load/syntax checks, JavaScript syntax checks, regression tests for recording success/refusal/timeout, alert fitting, and multiple bag ETA selection. Both installable archives are built and inspected for version and schema contents.

Limitations: GNOME Shell 42 and Jetson hardware remain untested. Interactive desktop checks across themes, display scales and resolutions have not been performed for this release; the existing README screenshots predate these changes.
