# Moni v0.0.13

- **Fix: Orca bubbles never showed on a real desktop.** A session's chip is rebuilt when its state changes, and the bubble was placed before the new chip had a position: it got x = NaN, which left it unallocated and invisible for good. Bubbles now wait for the chip to be laid out.
- **Bubbles appear within a second.** Orca rewrites `~/.config/orca/agent-hooks/last-status.json` on every agent hook event; Moni watches it and reads the sessions right away instead of waiting for the next 3 s poll (at most one read per 1.5 s).
- **A failed read no longer wipes the bar.** One or two failed `orca-ide` calls keep the last known sessions and bubbles.
- **Question choices are stacked full width and numbered**, so four long options fit instead of overflowing the bubble.
- **Type in the bubble** (with *Answer from the bubble* on): a question bubble has a field for a typed answer (Claude Code's "Type something"), and a finished session's bubble has a field for the next prompt. Click it, type, Enter; Escape or a click elsewhere cancels.

Validated on a real GNOME 46 X11 desktop: a waiting Claude Code session showed its bubble under its chip within a second; a choice button, a typed answer (English and Korean) and a next prompt for a finished session all reached the agent. Before the fix the Shell log showed `clutter_actor_allocate: assertion '!isnan (...)'` for every bubble.
