# Moni v0.0.11

- **Orca sessions** on the left of the top bar, next to Activities: one status dot and a name per agent session in the [Orca](https://github.com/stablyai/orca) app. Green pulses while working, yellow waits on you, blue is finished and unseen.
- **Hover** for a card with the last request and reply, branch and PR; **click** to jump to that session's terminal tab and bring Orca to the front.
- **Bubbles** drop from a session when it finishes or starts waiting on you. Waiting bubbles stay until answered. Do Not Disturb silences them.
- **Answer from the bubble** (off by default): Claude Code questions and permission prompts get their choices as buttons.
- **Shown sessions**: tick sessions in Settings to always show them in your order; with none ticked the most recently active appear (4 by default). The rest are in the ⌄ list.

Reads `orca-ide worktree ps --json` every 3 s while an agent is working, every 10 s otherwise, and not at all while no Orca window is open. Nothing appears without Orca.

Validated with unit tests on real `worktree ps` output, including a captured question from a waiting Claude Code session, and in an isolated headless GNOME 46 shell with sample sessions. Jumping to a session and answering from a bubble need a real Orca window and were not exercised there.
