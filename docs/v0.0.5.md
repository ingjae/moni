# Moni v0.0.5

PM2 and Docker monitoring, plus feedback links.

- **PM2** (`PM2 2/3` badge): online/stopped/errored apps with CPU, memory, restarts, uptime and last exit code. Turns red on an errored app or a crash loop (3+ crashes in 5 min) and notifies on crashes. Read from `~/.pm2` files and `/proc` — the `pm2` CLI is never polled.
- **Docker** (`DOCKER 3` badge): running and exited containers with CPU, memory and status. Turns red while a container is unhealthy, restarting or crash-looping; notifies on a non-zero exit, a restart or a failing health check. One request to the Docker Engine socket every 3 s plus cgroup files — no `docker` CLI. Restarts are detected by a new container init PID, so fast `--restart` policies are caught too.
- Settings → **About**: GitHub and "Report an issue" links. README gains a Feedback section.
- Fix: the "Screenshot & recording" settings group title was not shown (Pango markup was not escaped).
- New keys: `show-pm2`, `notify-pm2`, `show-docker`, `notify-docker`.

Validated on GNOME 46 in an isolated nested Wayland shell with PM2 7.1.1 (online / stopped / crash-looping apps, compared against `pm2 jlist`) and Docker 29.1.3 (real containers plus unhealthy, restart-looping and exit-7 test containers): badges, red alert state, cards, notifications, option on/off, and extension disable/enable ×3 (PM2 run).

Both GNOME 42–44 and 45–48 archives are included. The GNOME 42–44 runtime, root or custom-`PM2_HOME` PM2, rootless Docker and Podman were not tested.
