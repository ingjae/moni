# Moni v0.0.3

Follow-up fixes found while exercising v0.0.2 in actual GNOME/GTK windows.

- Restore readable dashboard text colors in light and dark themes.
- Keep long titles inside the menu at large text sizes.
- Refit panel chips before redraw on theme and geometry changes; show a compact monitor icon when chips do not fit.
- Preserve PopupMenu registration for the scrolling dashboard.
- Fix text annotation rendering/export with PangoCairo, including Unicode.
- Use allocated graph widths for history time labels.
- Add `make test-ui` to exercise actual GTK rendering, per-tool pixel changes, undo, source-resolution export and image boundaries.

Validated on GNOME 46 in isolated Wayland sessions: 800×600 with light/dark themes at 100/125/150/200% text size; 1920×1080 at 200% display scale; actual screenshot → editor, PNG clipboard, save, pin, and WebM recording start/stop. See `docs/ui-validation.md` for full evidence and coverage limits.

Both GNOME 42–44 and 45–48 installable archives are included. GNOME 42–44 session behavior and Jetson hardware remain untested; native X11, fractional scaling and multiple monitors were not covered in this run.
